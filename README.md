# Inventory Manager

Expo-based inventory app with a local SQLite product database.

## Scan test codes

Use the examples below to test scanning from the GitHub page. Each row contains
the same value as a QR code and a Code 128 barcode. Add the value in the
product's `code` field, then scan either image from another device.

| Product | Code | QR code | Barcode |
| --- | --- | --- | --- |

| Demo Chair | `DEMO-CHAIR-003` | ![QR code for DEMO-CHAIR-003](https://quickchart.io/qr?text=DEMO-CHAIR-003&size=220&margin=4) | ![Barcode for DEMO-CHAIR-003](https://quickchart.io/barcode?type=code128&text=DEMO-CHAIR-003&format=svg&width=360&height=120&includeText=true) |

phone's scanner at the image. Keep the full code visible, including the
barcode's quiet space around the bars.
